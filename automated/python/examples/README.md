# Gestaltor Automated Examples

The following concepts are shown in the respective examples:

## Simple
    - initialize runtime
    - create handle
    - use glTF interface
    - load file 
    - set value
    - save file

## Optimize Asset
    - apply Draco Mesh Compression
    - convert image size and format
    - clean unused properties
    - catch exceptions

## Create Meshes
    - start with an empty glTF
    - create scene and add nodes
    - transform nodes 
    - create meshes
    - lookup referenced mesh material
    - edit material 

## Edit Material
    - iterate over glTF properties
    - check if specific property exists
    - set material property


## Merge Assets
    - merge glTF files
    - dereference scene node
    - clone properties

## Assemble
    - load config file
    - merge glTF files
    - arrange merged glTF assets in a final scene
